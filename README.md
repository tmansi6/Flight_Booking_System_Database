# Flight_Booking_System_Database
This project is a secure, role-based employee login and authentication system built entirely using SQL Server. It handles employee data, login credentials, and role-based permissions (e.g., only supervisors can reset passwords). Key features include password hashing, salting, secure authentication, and robust access control.

## 🛠️ Features
- 🔐 Secure login using SHA2_512 password hashing and unique salt per user
- 👨‍💼 Role-based access (e.g., supervisors can reset passwords)
- 🧾 Stored procedures for authentication and user management
- ⚠️ Error handling with informative messages
- 📦 Normalized database design with referential integrity
